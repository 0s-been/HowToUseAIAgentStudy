# DX12Framework

DirectX 12 기본 프레임워크. 그래픽 작업의 출발점으로 쓰려고 단계적으로 만든 학습용 코드다.

체커 무늬 바닥 위에 큐브가 회전하고, WASD와 마우스로 그 안을 돌아다닐 수 있는 것까지가 현재 범위다.
그 과정에 DX12의 기본기가 빠짐없이 들어가 있다 —
디바이스 · 커맨드 큐 · 펜스 동기화 · 스왑체인 · 디스크립터 힙 · 루트 시그니처 · PSO ·
리소스 상태 전이 · 업로드/디폴트 힙 구분 · 프레임 자원 다중화.

외부 라이브러리 의존성은 없다. (흔히 쓰이는 `d3dx12.h`도 쓰지 않는다.)

## 빠른 시작

1. Visual Studio 2022로 `DX12Framework.sln`을 연다.
2. 구성을 **Debug | x64**로 두고 빌드 후 실행한다.

요구 사항은 Visual Studio 2022(v143 툴셋), Windows 10 SDK, DirectX 12를 지원하는 GPU다.

| 입력 | 동작 |
|---|---|
| `W` `A` `S` `D` | 앞 / 왼쪽 / 뒤 / 오른쪽 이동 |
| `Q` `E` | 아래 / 위로 이동 |
| `Shift` (누른 채) | 이동 속도 3배 |
| **마우스 우클릭 + 드래그** | 카메라 시야 회전 |
| `Space` | 큐브 회전 정지 / 재개 |
| `V` | 수직 동기화 토글 |
| `ESC` | 종료 |

## 저장소 구성

```
DX12Framework.sln
DX12Framework/          프레임워크 본체
├── Core/               창 · 타이머 · 로거 · 예외 · 애플리케이션 수명주기
├── Input/              키보드 / 마우스 입력
├── Graphics/           디바이스 · 스왑체인 · 파이프라인 · 메시 · 카메라 · 렌더러
└── Shaders/            HLSL (런타임 컴파일)
Docs/
└── DX12_Framework_WorkLog.md   단계별 작업 로그
```

빌드 방법, 파일별 역할, 한 프레임의 흐름, 확장 가이드는
**[`DX12Framework/README.md`](DX12Framework/README.md)** 에 정리되어 있다.

각 단계에서 무엇을 왜 그렇게 결정했는지는
**[`Docs/DX12_Framework_WorkLog.md`](Docs/DX12_Framework_WorkLog.md)** 에 남겨 두었다.
DX12를 처음 보는 상태에서 순서대로 따라가려면 이쪽이 읽기 좋다.

## 참고

이 저장소에는 원래 DirectX 11 기반 프로젝트(`DirectXProj`)가 함께 있었다.
앞으로의 작업을 DX12로 일원화하면서 제거했고, 필요하면 삭제 이전 커밋에서 확인할 수 있다.
